# API Reference

Base URL: `http://localhost:8000/api/v1`

All responses are JSON. Error responses follow the format:
```json
{ "detail": "Error description" }
```

> **Note**: All data returned by these endpoints is **simulated/synthetic**. Values are generated by estimation models, not measured from real infrastructure.

**Response:**
```json
{
  "types": [
    { "type": "ddos", "name": "DDoS", "description": "Distributed Denial of Service" },
    { "type": "brute_force", "name": "Brute Force", "description": "Brute force login attempt" },
    { "type": "port_scan", "name": "Port Scan", "description": "Port scanning activity" },
    { "type": "sql_injection", "name": "SQL Injection", "description": "SQL injection attempt" },
    { "type": "malware", "name": "Malware", "description": "Malware activity" },
    { "type": "suspicious_login", "name": "Suspicious Login", "description": "Suspicious login activity" }
  ]
}
```

### POST `/api/v1/simulator/simulate`

**Request body:**
```json
{ "attack_type": "ddos" }
```

**Response:** Full simulation pipeline result including event, threat, risk assessment, workload impact, energy impact, carbon impact, AI recommendation, and pipeline steps.

## AI Recommendations

### GET `/api/v1/recommendations`

**Query params:** `type` (security, carbon, energy, workload, general), `priority` (high, medium, low), `unread_only` (true/false)

### POST `/api/v1/recommendations/generate`

Generates new recommendations based on current system state.

### PATCH `/api/v1/recommendations/{rec_id}/read`

Marks a recommendation as read.

### PATCH `/api/v1/recommendations/{rec_id}/dismiss`

Dismisses a recommendation.
